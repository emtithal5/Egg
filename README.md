# نموش في مختبر الإنزيمات

مختبر افتراضي تفاعلي بالعربية لطالبات الصف الحادي عشر (الأحياء – الوحدة الثالثة: الإنزيمات).

افتحي `index.html` في المتصفح. لا يحتاج إلى تثبيت أي شيء.

المحطات: ١ القفل والمفتاح والتلاؤم المستحث · ٢ ماذا يحدث بعد الارتباط؟ · ٣ التفكيك والبناء · ٤ الليزوزيم في قطرة دمع · ٥ خفض طاقة التنشيط.

إعداد: أ.إمتثال العطابي

## مختبر «أيّ العوامل الحفّازة أسرع؟»

افتحي `catalase-lab.html`: مقارنة سرعة تفكّك بيروكسيد الهيدروجين بسبعة أنابيب (قيم محاكاة تعليمية).
