### الأدوات المستخدمة فعليًا
| الأداة | ما أُنجز |
|---|---|
| **ElevenLabs** (متصل) | توليد 47 مقطع تعليق بصوتين مرخّصين من المكتبة: **Reem** (لكنة عُمانية) للشيف رقية و**Wiam** (فصحى) للراوية، نموذج `eleven_v4` مع وسوم الأداء؛ و7 مؤثرات صوتية (سوق، باب خشبي، فرن، أوانٍ، Whoosh، رنين الروابط، قطرة ماء) بنموذج Sound Effects v2 |
| **Python + Cairo** | رسم كل التراكيب الكيميائية برمجيًا بدقة (هاورث، فيشر، الروابط الجلايكوسيدية، النشا، الجلايكوجين، السليلوز) وتحريكها – بدل توليدها بالنص |
| **Python + Pillow (Raqm)** | النصوص العربية المشكّلة صحيحًا، اللوحات الخشبية، البطاقات، حركات الكاميرا (Push-in / Tracking / Pull-back / Macro zoom) على لوحات المود بورد |
| **FFmpeg / libass** | ترميز المشاهد، المزج الصوتي (Ducking للموسيقى تحت الصوت، Loudness)، دمج الترجمة، طبقة التوقيع الثابتة، التصدير النهائي |

### ملاحظات مهمة بصراحة
- **أسلوب الحركة:** الفيلم Motion Graphics سينمائي 2.5D (حركات كاميرا على صور المود بورد + رسوم جزيئية متحركة)، وليس 3D حقيقيًا ولا فيديو مولّدًا بالذكاء الاصطناعي. الشخصية لا تتكلم بشفاه متحركة؛ تظهر في إطار ذهبي ثابت مع حركة خفيفة أثناء كلامها.
- **الصورة الحقيقية للشيف رقية لم تُستخدم داخل الفيلم ولم تُحرَّك، ولم يُستنسخ صوتها.** استُخدمت الشخصية المرسومة المعتمدة من المود بورد. يلزم الحصول على موافقة صاحبة الصورة قبل أي Image-to-Video أو Lip-Sync لصورتها الحقيقية.
- **التوقيع** «أ. إمتثال العطابي» طبقة مستقلة (PNG بخط Amiri) أُضيفت في التصدير النهائي أسفل يمين الشاشة، ثابتة من أول إطار لآخر إطار دون حركة، بهامش آمن، ولا تتداخل مع الترجمة (الترجمة محصورة في وسط الشاشة).

## إعادة البناء
```bash
pip install pycairo pillow numpy        # + ffmpeg مع libass
python3 tools/build.py timeline          # التوقيتات + SRT/ASS
python3 tools/build.py stills            # صور معاينة لكل مشهد
python3 tools/build.py scenes            # المشاهد (4 عمليات متوازية)
python3 tools/build.py audio             # المزج الصوتي
python3 tools/build.py final             # الفيلم النهائي
```
لتعديل نص: حرّر `script/script.json`، أعد توليد المقطع في ElevenLabs بالاسم نفسه في `audio/vo/`، ثم شغّل `timeline` و`scenes` و`audio` و`final`.
