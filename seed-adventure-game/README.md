# مغامرة البذرة في وادي الحياة

لعبة منصات تعليمية لدرس دورة حياة النبات، للصف الخامس (منهج كامبردج – سلطنة عُمان).
إعداد وتصميم: أ. إمتثال العطابي

## التشغيل
افتحي `index.html` في أي متصفح (Chrome أو Edge أو Safari). لا تحتاج اللعبة إلى تثبيت أي برنامج، وتعمل على السبورة التفاعلية والحاسوب والآيباد.
تُحمَّل الخطوط من Google Fonts عند توفر الإنترنت، وبدونه تعمل اللعبة بخطوط الجهاز.

## التحكم
- لوحة المفاتيح: السهمان ← → للحركة، والمسافة أو ↑ للقفز، والأرقام ١ ٢ ٣ لاختيار الإجابة.
- اللمس: أزرار الحركة أسفل اليسار، وزر «قفز» أسفل اليمين.
- أعلى الشاشة: كتم الصوت، وإعادة اللعب، وملء الشاشة.

## البوابات الثماني
سر البداية ← الاستيقاظ ← النبتة الصغيرة ← سر الأزهار ← مهمة التلقيح ← كنز الطماطم ← حديقة النباتات الحولية ← بستان النباتات المعمرة.

- الإجابة الخاطئة لا تُنهي اللعبة: تظهر تلميحة علمية ثم تُعاد المحاولة.
- عند نفاد القلوب الثلاثة يُحذف الخيار الخاطئ المتبقي.
- النجوم: ٣ للإجابة من المحاولة الأولى، و٢ بعد خطأ واحد، و١ بعد ذلك.
