# منظومة تغذية أجهزة الإرسال بالطاقة — فيديو تقني ثلاثي الأبعاد

فيديو تدريبي (1920×1080، 30 إطارًا/ث، 68 ثانية، بدون صوت) يشرح مسار الطاقة من لوحة الكهرباء العمومية إلى أجهزة الإرسال عبر وحدة الطاقة، واستمرار التغذية من البطاريات الاحتياطية عند انقطاع المصدر.

الملف الناتج: `power-feed-system.mp4`

## التسلسل الزمني

| الزمن (ث) | المحتوى |
|---|---|
| 0 – 5 | العنوان فوق لقطة عامة للمحطات الثلاث |
| 5 – 11 | ظهور أسماء المحطات وبناء مسار التغذية بالتتابع: اللوحة ← التقويم ← ناقل DC ← خرج التغذية ← أجهزة الإرسال |
| 11 – 24.5 | **الحالة الأولى** (أزرق): الكهرباء متوفرة، البطاريات في وضع الشحن/الاستعداد (تدفق خافت نحوها) |
| 24.5 – 26 | الانقطاع: يطفأ مؤشر اللوحة ← يتجمد ويخفت مسار الدخل العمومي ← يتوقف الشحن ← تبدأ البطاريات بالتغذية |
| 26 – 43 | **الحالة الثانية** (أخضر): البطاريات ← ناقل DC المشترك ← خرج التغذية ← أجهزة الإرسال |
| 44 – 60 | مقارنة الحالتين بالتتابع من زاوية كاميرا ثابتة |
| 60 – 68 | لقطة ختامية ثابتة: أجهزة الإرسال تعمل أثناء الانقطاع |

## الافتراضات الهندسية (تمثيل عام)

- البطاريات موصولة على **ناقل DC مشترك** مع وحدات التقويم، وهو الترتيب الشائع في منظومات طاقة الاتصالات. لذلك يظهر انتقال التغذية على مستوى الناقل دون أي قاطع تحويل أو مرحّل أو فصل ميكانيكي.
- لا تُعرض قيم جهد ولا نوع محدد لوحدة الطاقة ولا علامات تجارية.
- عدد وحدات التقويم (3) وكتل البطاريات (8 على رفّين) **توضيحي فقط** ولا يمثّل ترتيب البطاريات الفعلي.
- لا يظهر فاصل الجهد المنخفض (LVD) ولا قاطع البطاريات لأن وجودهما غير مؤكد.

إذا اختلفت المنظومة الحقيقية عن ذلك (مثل وجود مسار منفصل للبطاريات أو UPS بتيار متناوب)، فعدّل المسارات في `src/scene.js` (الدالة `addFlow`).

## إعادة التوليد

```bash
npm install
NODE_PATH=$(npm root -g) node render.mjs power-feed-system.mp4      # الفيديو كاملًا
NODE_PATH=$(npm root -g) node render.mjs --stills 15,30,62          # صور ثابتة للمراجعة في frames/
```

يتطلب Node 18+ وPlaywright (Chromium) وffmpeg. المشهد مبني بـ Three.js ويُرسم إطارًا بإطار بشكل حتمي عبر `window.renderAt(t)`.
